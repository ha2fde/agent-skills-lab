# Change log

## 1.0.0 — 2026-11-06
- Established a single concise ASF security-reporting email format.
- Separated verified impact from hypotheses and source-only observations.
- Removed default CVSS/CVE requests, prior-advisory comparisons, attachments and verbose evidence bookkeeping.
- Standardized credit and sign-off.
- Required user-controlled final review and sending.
- Added strict pre-commit embargo controls for all public repository metadata and content.

This log intentionally contains no information about unpublished findings.
