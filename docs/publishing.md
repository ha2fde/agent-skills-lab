# 发布与发现

源仓库承载版本和资源，索引站承担搜索与发现；两者是不同步骤。
GitHub 提交不会保证被 skills.sh 收录、立即出现在搜索或取得排名。

1. 准备可用技能、清晰描述、使用示例和验证记录。
2. 确认整个仓库与历史可公开、确定许可证。
3. 使用正式仓库名更新安装命令与链接。
4. 在干净环境中用 skills CLI 列出并安装选定技能，核对发现结果。
5. 查看 skills.sh 当前官方说明和实际页面确认是否被索引；不承诺收录时间或排名。

本仓库已于 2026-09-30 公开，可以通过 GitHub 访问和安装。尚未验证 skills.sh 的实际收录，不宣称已上榜。
公开前对主分支历史 10 次提交、33 个不同文件版本做常见凭据模式检查，未发现匹配；这不等于全面安全认证。现有历史含维护者提交邮箱，经维护者确认保留。
公开可见性不等于统一开源授权；WorkBuddy Skill 保留 MIT，其余内容授权以实际许可证为准。
