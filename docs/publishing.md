# 发布与发现

源仓库承载版本和资源，索引站承担搜索与发现；两者是不同步骤。
GitHub 提交不会保证被 skills.sh 收录、立即出现在搜索或取得排名。

1. 准备可用技能、清晰描述、使用示例和验证记录。
2. 确认整个仓库与历史可公开、确定许可证。
3. 使用正式仓库名更新安装命令与链接。
4. 在干净环境中用 skills CLI 列出并安装选定技能，核对发现结果。
5. 查看 skills.sh 当前官方说明和实际页面确认是否被索引；不承诺收录时间或排名。

当前私有仓库适合自用和授权协作，不应期待公共发现。不得通过安装私有仓库来宣传其已公开收录。

参考：https://skills.sh/docs
